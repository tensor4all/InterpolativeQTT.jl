InterpolativeQTT.jl

InterpolativeQTT.jl implements the multiscale interpolative construction of Quantized Tensor Trains (QTTs) described in Lindsey (2023).

Content

  • Single-scale interpolation
  • Multiscale interpolation
  • Adaptive interpolation
  • Sparse interpolation
  • Inversion

Installation

julia> ]
pkg> add InterpolativeQTT

Quick start

import InterpolativeQTT
import TensorCrossInterpolation as TCI

f(x) = exp(-x^2)
K = 10
R = 8
tt = InterpolativeQTT.interpolatesinglescale(f, -2.0, 2.0, R, K)
println("Rank: ", TCI.rank(tt))
Rank: 9
g(x) = x == 0.0 ? 0.0 : 1 / x
tt_ms = InterpolativeQTT.interpolatemultiscale(g, 0.0, 1.0, 12, 25, [0.0])
println("Rank: ", TCI.rank(tt_ms))
Rank: 9

Examples

The Examples page walks through four worked examples:

ExampleFunctionMethod
Highly oscillatory function$\cos(x^2) + \sin(\pi x)$interpolatesinglescale
Narrow Gaussian$e^{-x^2/(2\alpha^2)},\ \alpha=0.01$interpolateadaptive
Lorentzian peak$\alpha/\sqrt{\alpha^2+(x-\tfrac{1}{2})^2}$interpolatesinglescale_sparse
QTT inversion$e^{-x^2+\cos x}$invertqtt

See the API Reference page for the full list of exported functions. The main entry points are:

FunctionDescription

interpolatemultiscaleMultiscale QTT with explicit singularities
interpolateadaptiveAdaptive refinement QTT
interpolatesinglescale_sparseSparse (banded) single-scale QTT
